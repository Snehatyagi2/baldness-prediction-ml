# Baldness Prediction using ML

## Overview
This project analyzes genetic and lifestyle factors affecting baldness.

## Features
- Synthetic dataset based on biological research
- Machine learning models (Logistic Regression, Random Forest)
- Prediction system

## Key Insights
- Genetic risk is the strongest predictor
- DHT plays a major role
- Lifestyle modifies severity

## Disclaimer
This is a synthetic dataset and not for medical use.
